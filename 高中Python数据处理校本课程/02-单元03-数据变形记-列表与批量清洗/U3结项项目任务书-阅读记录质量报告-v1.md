# U3 单元结项项目任务书

## 《阅读记录质量报告：哪些记录可以进入汇总？》

**项目类型：** 个人完成或两人结对完成、同伴试运行的 U3 单元结项项目。  
**建议用时：** 第 14—15 课内完成，另可用 20—30 分钟完善。  
**你将交付：** 一个可运行的数据整理器程序、一张数据“变形”流程图、一张测试记录表、一份数据质量与清洗边界说明。  
**本项目只使用教学模拟数据。** 不输入真实学生姓名、阅读记录、成绩、健康信息、联系方式、精确位置或其他可识别个人数据。

> 你的目标不是把所有数据变得整齐，而是完成一次可追溯的数据处理闭环：**观察原始记录 → 写出清洗规则 → 批量处理 → 保留问题日志 → 汇总并说明边界。**

## 一、情境与任务

学校“阅读数据小组”准备制作一份教学演示报告。教师提供了一组**模拟的一周阅读记录**，其中故意包含空格、单位混入、缺失值、无效文本和可能需要复核的记录。小组想回答：

> “这组模拟记录中，有多少条可以按当前规则进入汇总？有效记录的总分钟数和平均值是多少？哪些记录不能自动确认？我们还能、不能从这组数据得出什么结论？”

你需要完成一份“阅读记录质量报告”。程序必须同时输出：清洗后的有效记录、未进入汇总的问题记录及原因、有效记录的汇总结果。你不能默默删除问题记录，也不能把空白自动补成 0。

## 二、给定数据与字段口径

请使用下列教学模拟数据。允许教师提供同结构的另一组模拟数据，但不得替换为真实同学的阅读或学习记录。

```python
raw_records = [
    {"record_id": "R01", "day": "周一", "minutes": "25"},
    {"record_id": "R02", "day": "周二", "minutes": " 35 "},
    {"record_id": "R03", "day": "周三", "minutes": ""},
    {"record_id": "R04", "day": "周四", "minutes": "30分钟"},
    {"record_id": "R05", "day": "周二", "minutes": "35"},
    {"record_id": "R06", "day": "周五", "minutes": "abc"},
    {"record_id": "R07", "day": "周六", "minutes": "0"},
]
```

| 数据现象 | 示例 | 本项目建议的处理 | 不能做的事 |
|---|---|---|---|
| 多余空格 | `" 35 "` | 去除首尾空格，再按约定转成数字。 | 直接覆盖原始值而不说明。 |
| 单位混入 | `"30分钟"` | 在本项目明确约定后去除单位，再转成数字。 | 看到任意文字都强行删除。 |
| 缺失值 | `""` | 标记为缺失，写入质量日志，不计入均值。 | 擅自补成 0 或任意数字。 |
| 无效文本 | `"abc"` | 标为待复核，保留编号、原始值和原因。 | 默默删除，使记录无法追溯。 |
| 可能重复 | 周二两条记录 | 标记为“需要确认”，不在没有规则时断言一定重复。 | 直接删除其中一条。 |
| 零值 | `"0"` | 按“非负整数分钟数”规则作为有效数值，是否合理要在说明中写出。 | 看到 0 就擅自改成缺失。 |

**字段口径：** `record_id` 是模拟记录编号；`day` 是模拟日期标签；`minutes` 是原始文本形式的分钟数。按本项目规则，只有能解释为非负整数的值才进入有效汇总；不能解释的值进入问题日志。

## 五、测试是项目的一部分

运行前先写出预期，运行后记录实际结果。至少完成下列 6 组测试。

| 测试类型 | 数据改动 | 运行前要判断什么 | 实际结果 | 我检查了什么？ |

## 七、数据质量与清洗边界说明

## 九、评价重点

教师与同伴重点检查“程序可运行、处理可追溯、规则能解释、汇总有口径、结论有边界”，不以代码长短、输出是否漂亮或清洗后有效数是否更多作为主要依据。

| 关注点 | 达标表现 |
|---|---|
| 数据结构与批量处理 | 正确使用列表、字典、函数和循环处理多条记录。 |
| 清洗规则与日志 | 能区分至少 4 类数据问题，并保留问题记录和原因。 |
| 汇总与解释 | 同时报告有效数、问题数和统计结果，说明哪些记录未进入计算。 |
| 测试与调试 | 覆盖格式、缺失、无效、零值和规则变化，能解释一次修订。 |
| 责任与边界 | 不把模拟记录推断为真实阅读习惯、学习能力或长期规律。 |
