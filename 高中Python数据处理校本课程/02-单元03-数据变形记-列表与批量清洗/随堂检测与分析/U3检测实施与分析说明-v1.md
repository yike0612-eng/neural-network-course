# U3 随堂检测实施与分析说明 v1.0

## 一、实施边界

本检测建议在 U3 第 5 课程序自测与展示后独立完成，用时 10 分钟。它的用途是帮助教师判断学生对数据结构、清洗规则、质量日志、批量处理和可信汇总的理解，不用于公开排名、惩罚或高风险学生决策。

每份答卷只填写匿名 `response_id` 和 Q1—Q10 的 A/B/C/D 选项。不记录姓名、学号、成绩、联系方式、真实阅读记录或其他敏感个人信息。教师只解释班级、题目与知识点层面的汇总结果。

## 二、使用步骤

1. 发放 `U3学生随堂检测问卷-v1.md`，提示学生独立答题，不填写身份信息。
2. 将选项录入 `u3_quiz_responses_template.csv`；每行只代表一份匿名答卷。
3. 在本目录运行：

```bash
python analyze_u3_quiz.py u3_quiz_responses_template.csv u3_quiz_config.json --output-dir quiz_report
```

4. 阅读 `quiz_report/匿名随堂检测汇总报告.md`，优先查看“优先修订”和“需巩固”的知识点。
5. 把检测结果与数据整理器、流程图、质量反思、同伴审阅和课堂观察一起解释；试教后只选择一项 P0 修订。

## 三、结果解释

| 标签 | 暂定工作阈值 | 建议教师行动 |
|---|---:|---|
| 稳定 | 正确率 ≥ 80% | 在 U4 的 CSV 清洗中自然复现，无需额外拉长讲授。 |
| 需巩固 | 正确率 60%—79% | 用 5—10 分钟的记录卡、转换箭头、循环追踪或质量日志阅读补强。 |
| 优先修订 | 正确率 < 60% | 进入 U4 前确定一个具体资源修订，例如增加“缺失、零、无效”对照卡。 |

这些阈值是课程资源改进信号，不是学生等级。低正确率首先提示教师检查任务说明、数据案例、练习机会、课堂时间和概念支架，不能直接归因于学生能力。

## 四、检测内容对照

| 题号范围 | 核心检查 | 可对应的课堂资源 |
|---|---|---|
| Q1—Q2 | 列表、字典、键和值 | 第 1 课数据卡与结构标注。 |
| Q3—Q5 | 格式标准化、缺失、质量日志 | 第 2 课规则表与单值预测。 |
| Q6—Q8 | 函数接口、循环、记录可追溯性 | 第 3 课去向表与批量输出。 |
| Q9—Q10 | 可信汇总与规则边界 | 第 4—5 课质量说明与展示。 |

> 任何单题结果都不能单独决定是否推进 U4。只有检测、课堂观察和学生作品共同指向同一阻碍时，才把它设为下一版的 P0 修订。
