## 题目

### 1. 规则要可判断

下面哪一句最适合直接写进程序作为条件？

A. 如果天气不太好，就别外出。  
B. 如果 `weather == "雨"`，就给出室内活动建议。  
C. 如果学生感觉有一点累，就休息。  
D. 如果时间差不多够，就去运动。  

### 2. 比较与赋值

在 Python 中，哪一个表达式是在判断 `free_minutes` 是否等于 10？

A. `free_minutes = 10`  
B. `free_minutes == 10`  
C. `free_minutes >= "10"`  
D. `print(free_minutes)`  

### 3. `not` 的含义

```python
if not task_done:
    return "先完成当前任务"
```

当 `task_done` 的值是 `False` 时，函数会怎样？

A. 返回“先完成当前任务”。  
B. 跳过这条分支，直接结束。  
C. 一定返回室内活动建议。  
D. 一定报错。  

### 4. 优先级

如果规则是“任务未完成时先完成任务；否则时间少于 10 分钟时短时放松；否则雨天时室内活动”，那么下面哪一种输入最应该优先得到“先完成任务”的建议？

A. 晴天、30 分钟、任务已完成。  
B. 雨天、20 分钟、任务已完成。  
C. 雨天、5 分钟、任务未完成。  
D. 晴天、9 分钟、任务已完成。  

### 5. 边界测试

规则写为：

```python
elif free_minutes < 10:
    return "短时放松"
```

当 `free_minutes` 恰好是 10 时，下面哪句话正确？

A. 会进入“短时放松”分支。  
B. 不会进入这一分支，会继续检查后面的规则。  
C. 一定报错。  
D. 会同时进入所有分支。  

### 6. 多分支结构

为什么这里适合使用 `if/elif/else`，而不是写成多个没有关联的 `if`？

A. 因为一组输入通常只需要一条按优先级给出的建议。  
B. 因为 `elif` 会让 Python 忘记前面的条件。  
C. 因为 `if` 不能比较数值。  
D. 因为多个 `if` 不能运行。  

### 7. 函数的输入和返回

```python
def suggest_activity(weather, free_minutes, task_done):
    return "阅读或散步"
```

下面哪一句正确？

A. `weather`、`free_minutes`、`task_done` 是函数输入；`return` 把建议交回外部代码。  
B. 三个参数都是固定输出。  
C. `return` 只负责把文字显示在屏幕上。  
D. 函数不能在循环中调用。
