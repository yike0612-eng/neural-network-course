# U2 随堂检测实施与分析说明 v1.0

## 一、实施边界

本检测建议在 U2 第 5 课自测与展示后独立完成，用时 10 分钟。它服务于形成性诊断：帮助教师判断规则表达、优先级、函数测试和人工判断边界中哪一项需要改进。检测不用于公开排名、惩罚或高风险学生决策。

每份答卷只填写一个匿名 `response_id` 和 Q1—Q10 的 A/B/C/D 选项。不要录入学生姓名、学号、成绩、联系方式、行为记录或任何敏感个人信息。教师只解释班级、题目和知识点层面的聚合结果。

## 二、使用步骤

1. 发放 `U2学生随堂检测问卷-v1.md`，提醒学生独立作答，不写身份信息。
2. 将选项录入 `u2_quiz_responses_template.csv`；每行一份匿名答卷。
3. 在该目录运行：

```bash
python analyze_u2_quiz.py u2_quiz_responses_template.csv u2_quiz_config.json --output-dir quiz_report
```

4. 打开 `quiz_report/匿名随堂检测汇总报告.md`，先查看“优先修订”和“需巩固”项目。
5. 将结果与规则表、测试表、流程图、同伴试运行和课堂观察结合；试教后只确定一项 P0 修订。

## 三、结果解释

| 标签 | 暂定工作阈值 | 适合的教师行动 |
|---|---:|---|
| 稳定 | 正确率 ≥ 80% | 在下一单元自然复现，不额外拉长讲授。 |
| 需巩固 | 正确率 60%—79% | 用 5—10 分钟的预测、规则排序、边界追踪或同伴解释补强。 |
| 优先修订 | 正确率 < 60% | 在进入后续内容前选择一项具体资源修订，例如增加组合测试卡。 |

这些阈值不是学生成绩等级。较低正确率首先提示教师检查：题干是否清楚、是否给过足够练习、规则案例是否合适、时间是否够用，以及学生是否能够把纸面规则与代码输出对应起来。

## 四、检测内容对照

| 题号范围 | 核心检查 | 可对应的课堂资源 |
|---|---|---|
| Q1—Q3 | 可判断规则、`==`、`not` | 第 1 课规则表与布尔表达式预测。 |
| Q4—Q6 | 优先级、边界、多分支 | 第 2 课排序卡、9/10/11 测试。 |
| Q7—Q8 | 函数接口、循环处理记录 | 第 3—4 课函数骨架与情境列表。 |
| Q9—Q10 | 组合测试、人工判断边界 | 第 4—5 课测试表与反思。 |

> 任何单题结果都不能单独决定是否推进 U3。只有当检测、课堂观察和学生作品都指向同一阻碍时，才将其设为下一版的 P0 修订。
