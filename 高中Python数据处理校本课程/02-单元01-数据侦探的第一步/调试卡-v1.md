# U1《数据侦探的第一步》调试卡 v1.0

## 使用规则

每张卡都是一个小型“代码侦探任务”。先不要请教师直接给答案；请依次完成四步：**阅读现象、定位位置、作出最小修改、再次运行验证**。修复后，要能向搭档解释“为什么这处修改有效”。

> 调试的目标不是一次不出错，而是让错误变成可读、可找、可验证的信息。
