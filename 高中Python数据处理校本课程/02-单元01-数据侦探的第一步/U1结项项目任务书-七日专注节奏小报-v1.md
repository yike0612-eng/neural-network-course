# U1 单元结项数据处理项目任务书

## 《七日专注节奏小报：哪些日子达到了目标？》

**项目类型：** 个人完成、同伴试运行的 U1 单元结项项目。  
**建议用时：** 第 4—5 课内完成，另可用 15—20 分钟完善。  
**你将交付：** 一份可运行的 Python 程序、一张 IPO 知识图、一张证据与边界说明卡。  
**本项目使用教学模拟数据。** 不输入姓名、学号、成绩、健康、精确位置、家庭信息或真实个人日程。

> 你的目标不是写很多代码，而是完成一次完整的数据处理闭环：**提出一个清楚问题 → 处理给定数据 → 输出结果 → 解释结果与边界。**

## 一、情境与任务

学校“学习方法社”正在准备一张关于专注学习节奏的小海报。教师提供了一组**教学模拟的 7 天番茄钟完成次数**。每完成一个番茄钟，代表完成了 25 分钟专注学习。社团希望回答：

> “在这 7 天的模拟记录中，有几天达到每天至少 3 个番茄钟的目标？平均每天完成多少个？下一周可以提出什么谨慎的建议？”

你需要用 Python 完成一份“七日专注节奏小报”。你的程序不能替人判断学习能力，也不能用这 7 天数据推断长期习惯、成绩或任何人的表现。

## 二、给定数据与字段口径

使用下列模拟数据，也可以在教师允许的范围内改写数值，但不要改成真实可识别的个人数据。

```python
weekdays = ["周一", "周二", "周三", "周四", "周五", "周六", "周日"]
focus_sessions = [2, 4, 3, 1, 5, 3, 2]
daily_goal = 3
```

| 字段 | 含义 | 可以回答什么 | 不能回答什么 |
|---|---|---|---|
| `weekdays` | 7 个模拟日期标签。 | 哪一天达到目标。 | 某个真实学生在哪里、做了什么。 |
| `focus_sessions` | 每天完成的模拟番茄钟次数。 | 总量、平均值、达标天数。 | 学习质量、健康状况或成绩变化。 |
| `daily_goal` | 每天至少完成的目标次数。 | 是否达到设定目标。 | 目标是否适合所有人。 |

## 三、最低可运行版本

你的程序必须完成下列五项工作。

| 编号 | 程序要求 | 必须用到的知识 |
|---:|---|---|
| 1 | 显示项目标题和每天的模拟记录。 | `print()`、变量、列表。 |
| 2 | 逐天读取 `focus_sessions`。 | `for` 循环。 |
| 3 | 计算 7 天总番茄钟数。 | 累加。 |
| 4 | 计算平均每天完成次数。 | 总量 ÷ 天数。 |
| 5 | 统计达到或超过 `daily_goal` 的天数，并给出一条建议。 | `if`、比较、计数。 |

你的输出至少要让读者看见：7 天总量、平均每天完成次数、达标天数，以及一条不夸大的建议。
