# U4 单元结项项目任务书

## 《校园阅读空间表格报告：从原始 CSV 到可信汇总》

**项目类型：** 个人完成或两人结对完成、同伴审阅的 U4 结项项目。  
**建议用时：** 第 19—20 课内完成，另可用 20—30 分钟完善。  
**你将交付：** 一个可运行的 CSV 处理脚本、一份数据字典、一张清洗流程图、一张分组汇总表和一份数据质量说明。  
**本项目只使用教学模拟数据。** 不采集真实学生出入记录、姓名、成绩、健康信息、联系方式或精确位置。

> 你的目标不是把表格改得“漂亮”，而是让读者知道：数据从哪里来、哪些记录进入了计算、哪些记录被标记、汇总结果的口径是什么。

## 一、情境与任务

学校“阅读空间改进小组”想了解一组模拟校园阅读空间记录。你需要使用 Python 读取 CSV，按明确规则清洗字段，再回答：

> “在这组教学模拟记录中，东区与西区的有效阅读分钟数如何汇总？有多少记录没有进入计算？哪些记录需要修复或人工复核？我们能否据此断言某个空间一定更适合所有人？”

你的报告必须同时包含**清洗过程**和**汇总结果**。不能只提交一个平均值，也不能默默删除空值、无效文本或疑似重复记录。

## 二、给定 CSV 与字段口径

教师提供文件 `reading_space_raw.csv`。基础数据如下：

```csv
date,space,visits,minutes
2026-04-01,东区,42,35
2026-04-02,东区,,40
2026-04-03,西区,38,abc
2026-04-03,西区,38,45
2026-04-04,东区,51,50
2026-04-05,西区,44, 30 
```

| 字段 | 含义 | 预期类型 | 本项目边界 |
|---|---|---|---|
| `date` | 教学模拟日期标签。 | 文本日期 | 只用于分组或展示，不推断长期趋势。 |
| `space` | 教学模拟空间名称。 | 文本 | 只允许东区、西区或教师提供的模拟类别。 |
| `visits` | 模拟访问次数。 | 非负整数 | 空白需标记，不能随意补值。 |
| `minutes` | 模拟阅读分钟数。 | 非负整数 | 去除约定空格后转换；无效文本进入问题日志。 |

程序必须满足下列要求。

| 编号 | 程序要求 | 检查方式 |
|---:|---|---|
| 1 | 使用 `csv.DictReader` 或等价方式按字段名读取 CSV。 | 能打印字段名并解释一行记录。 |

## 五、测试记录

每次运行前先写预期，运行后填写实际结果。至少完成 6 组测试。

| 测试类型 | 改动 | 运行前预期 | 实际结果 | 检查内容 |
|---|---|---|---|---|
| 基线 | 不改 CSV | 有效、问题、待复核数量分别是多少？ |  | 程序是否读取全部行。 |
| 空值 | 将 `visits` 空白保留 | 该行进入哪里？ |  | 空值没有被补成 0。 |
| 类型 | 将 `minutes` 的 `" 30 "` 保留 | 是否能按规则转成 30？ |  | 文本标准化和转换。 |
| 无效文本 | 将 `minutes` 改为 `abc` | 是否进入问题日志？ |  | 原始值和原因是否保留。 |
| 重复规则 | 复制一条完全相同的行 | 唯一键规则是否识别？ |  | 重复处理是否可追溯。 |
| 分组变化 | 将一条有效记录的 `space` 从东区改为西区 | 两组统计如何变化？ |  | 分组汇总是否随输入改变。 |
