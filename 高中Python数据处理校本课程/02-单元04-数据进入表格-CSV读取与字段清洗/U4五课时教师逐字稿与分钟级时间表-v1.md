# U4《数据进入表格：CSV读取与字段清洗》五课时教师逐字稿与分钟级时间表 v1.0

**对象：** 高一、高二；已完成 U1—U3。  
**课时：** 5 × 45 分钟。  
**基础路径：** Python 标准库 `csv`；若学校已配置 `pandas`，可将其作为选做扩展，不作为本单元最低要求。  
**核心问题：** 面对一份原始表格，哪些记录可以进入分析，哪些记录应修复、标记或留给人复核？  
**固定课堂句式：** “先看字段，再读记录；先写清洗规则，再运行代码；先说明记录数，再解释统计量。”

## 一、教学模拟数据

课堂使用教师提供的、无个人身份信息的“校园阅读空间使用记录”模拟 CSV。字段为 `date`、`space`、`visits`、`minutes`。学生不得采集真实学生出入记录、姓名、成绩、健康或精确位置数据。

```csv
date,space,visits,minutes
2026-04-01,东区,42,35
2026-04-02,东区,,40
2026-04-03,西区,38,abc
2026-04-03,西区,38,45
2026-04-04,东区,51,50
2026-04-05,西区,44, 30 
```

## 二、五课时总览

| 课次 | 核心问题 | 最小证据 |
|---:|---|---|
| 16 | 表格为什么“不干净”？ | 数据质量侦错表。 |
| 17 | Python 怎样读进 CSV？ | 字段、行、记录解释和读取输出。 |
| 18 | 怎样清洗并转换字段？ | 清洗前后记录数与问题日志。 |
| 19 | 怎样筛选并分组汇总？ | 一张可复核的分组汇总表。 |
| 20 | 怎样写可信数据说明？ | 清洗脚本、数据字典、质量说明和同伴审阅。 |

# 第 16 课：表格为什么“不干净”？

**本课目标：** 区分字段、记录、缺失、重复、类型不一致和异常文本；先写数据质量问题，不急着修复。

| 时间 | 教学环节 | 教师逐字稿与操作 | 学生活动与观察 |
|---|---|---|---|
| 0:00—5:00 | 从U3迁移 | **教师说：**“U3 中我们处理的是程序里的列表和字典。今天这些记录住进了 CSV 表格。表格看起来整齐，不代表字段真的可以直接计算。我们先侦错，暂不删除。” | 学生回顾有效列表、问题日志和原始记录保留原则。 |
| 5:00—12:00 | 观察 CSV | 投影模拟 CSV。**教师说：**“第一行告诉我们字段名称；下面每一行是一条记录。请找出至少四种需要注意的现象，但先不要把它们都叫错误。” | 学生圈出空值、`abc`、前后空格、潜在重复。 |
| 12:00—22:00 | 数据质量分类 | **教师说：**“请把现象分成可修复格式、缺失、无效、可能重复和需要口径确认。每一类都写：证据是什么、能否自动处理、需要保留什么。” | 完成数据质量侦错表。 |
| 22:00—32:00 | 字段口径 | **教师说：**“`visits` 是次数，`minutes` 是分钟文本。空白不等于零，`abc` 不等于数字，重复也不等于已证实错误。字段口径决定我们能否计算。” | 学生为四个字段写类型和含义。 |
| 32:00—40:00 | 小组质询 | **教师说：**“如果有人说‘把空白全部填 0’，你会问他什么？如果有人说‘两行一样就删除’，还缺什么信息？” | 小组互相质询并记录一条反例。 |
| 40:00—45:00 | 退出卡 | **教师说：**“写出一条你愿意自动修复的规则和一条必须保留人工复核的情形。下节课我们才让 Python 读取表格。” | 提交退出卡。 |

**即时调整：** 若多数学生认为缺失就是 0，补做“未知/零/无效”对照；若看不出重复风险，要求比较 `date+space` 与完整行两种唯一规则。

# 第 17 课：Python 怎样读进 CSV？

**本课目标：** 使用 `csv.DictReader` 读取 CSV；理解文件路径、字段名、行和字典记录；发现“读进来的数字通常仍是字符串”。

| 时间 | 教学环节 | 教师逐字稿与操作 | 学生活动与观察 |
|---|---|---|---|
| 0:00—5:00 | 回顾字段 | **教师说：**“昨天我们先确定了字段含义。今天程序只做一件事：把表格安全读进来，并确认它读到的内容是什么。” | 学生说出四个字段。 |
| 5:00—13:00 | 文件与路径 | 演示同目录文件。**教师说：**“先把脚本和 CSV 放在同一目录。路径错误不是数据错误，遇到问题先检查文件名、后缀和目录。” | 学生完成环境检查。 |
| 13:00—23:00 | `DictReader` | 演示 `with open(..., newline='', encoding='utf-8-sig') as file:` 与 `csv.DictReader(file)`。**教师说：**“每一行会变成一个字典，字段名来自第一行。请不要凭位置猜字段，先打印 `reader.fieldnames`。” | 学生读取字段名和第一条记录。 |
| 23:00—32:00 | 类型侦察 | **教师说：**“请打印 `row['visits']` 和它的类型。看到 42 了吗？它通常还是字符串 `'42'`。表格的样子不能替代类型检查。” | 学生观察字符串类型，填写字段类型表。 |
| 32:00—40:00 | 逐行输出 | **教师说：**“用循环输出日期和空间，不要一次打印所有内容。每次只问一个问题：读到了几条？哪些字段为空？” | 学生完成读取脚本并记录行数。 |
| 40:00—45:00 | 退出卡 | **教师说：**“写下 `DictReader` 解决了什么问题，以及它没有替我们解决什么问题。” | 学生提交退出卡。 |

**即时调整：** 若路径问题占用过多时间，教师提供已验证目录，学生先用纸面字段表继续；若学生把字符串直接相加，回到类型检查。

# 第 18 课：怎样清洗并转换字段？

**本课目标：** 对 CSV 行执行去空格、空值标记、整数转换和重复识别；保留清洗日志，比较清洗前后记录数。

| 时间 | 教学环节 | 教师逐字稿与操作 | 学生活动与观察 |
|---|---|---|---|
| 0:00—5:00 | 规则先行 | **教师说：**“今天不从 `int()` 开始，而从规则表开始。我们要决定：什么可以修，什么只能标记，什么需要复核。” | 学生复述四类清洗规则。 |
| 5:00—14:00 | 单字段函数 | 演示 `clean_integer(text, field_name)`。**教师说：**“函数接收原始文本，返回数字或问题原因。它不是把所有字符强行删掉，而是按字段口径处理。” | 学生手算空值、`' 30 '`、`'abc'` 的返回。 |
| 14:00—24:00 | 批量清洗 | **教师说：**“循环负责逐行读取，函数负责单字段判断，问题日志负责留下证据。三者分工不要混在一大段代码里。” | 学生补全 `clean_rows` 和 `issues`。 |
| 24:00—33:00 | 重复记录 | **教师说：**“重复需要唯一规则。若规则是 `date + space + visits + minutes`，两行完全相同才可标为重复；若只有日期和空间相同，不足以断言它们是同一条。” | 学生比较两种唯一键，选择并说明边界。 |
| 33:00—40:00 | 清洗前后对照 | **教师说：**“请报告原始行数、有效行数、问题行数和重复待复核数。清洗后少了几行，必须能解释去向。” | 学生填写前后对照表。 |
| 40:00—45:00 | 退出卡 | **教师说：**“写一句：为什么清洗日志不是多余工作？” | 提交退出卡。 |

**即时调整：** 若学生把重复直接删除，回到唯一键讨论；若所有文本都被 `replace`，提供 `-5`、`3.5` 和 `30分钟` 反例。

# 第 19 课：怎样筛选并分组汇总？

**本课目标：** 依据明确问题筛选记录；按 `space` 分组统计有效访问次数或分钟数；解释分母、未纳入记录和数据限制。

| 时间 | 教学环节 | 教师逐字稿与操作 | 学生活动与观察 |
|---|---|---|---|
| 0:00—5:00 | 从清洗到问题 | **教师说：**“清洗完成不等于分析完成。先问一个具体问题：在有效记录中，东区和西区的平均阅读分钟数分别是多少？” | 学生指出需要的字段和有效记录。 |
| 5:00—13:00 | 手工筛选 | **教师说：**“先在纸上把 `space == '东区'` 的有效记录圈出来，再写程序。筛选条件要能说清楚。” | 完成筛选表并预测结果。 |
| 13:00—25:00 | 分组字典 | 演示 `group_totals = {}`。**教师说：**“字典的键是空间，值可以是累计分钟数和记录数。每次更新都要问：这条记录是否有效？它属于哪一组？” | 学生实现分组累计。 |
| 25:00—34:00 | 汇总表 | **教师说：**“输出分组结果时必须带有效记录数。平均值没有分母就不完整。” | 学生输出空间、有效数、总分钟数、平均值。 |
| 34:00—40:00 | 解释边界 | **教师说：**“如果东区平均值更高，能不能说东区一定更适合阅读？不能。我们还没有场地容量、样本完整性或时间段信息。” | 学生写一条事实、一条谨慎解释、一条不能断言的结论。 |
| 40:00—45:00 | 收束 | **教师说：**“下节课要交付的不是漂亮数字，而是别人能复核的数据说明。” | 保存代码和汇总表。 |

**即时调整：** 若学生只显示平均值，强制补充有效记录数；若分组字典混乱，先用两条记录手动追踪键和值。

# 第 20 课：怎样写可信数据说明？

**本课目标：** 完成 CSV 清洗与统计脚本、数据字典、清洗流程图和质量说明；进行同伴审阅并说明下一步改进。

| 时间 | 教学环节 | 教师逐字稿与操作 | 学生活动与观察 |
|---|---|---|---|
| 0:00—5:00 | 交付说明 | **教师说：**“今天提交四件东西：脚本、数据字典、清洗流程图、数据质量说明。每个数字都要能回答：来自哪些记录？哪些被排除？为什么？” | 学生打开量规和提交清单。 |
| 5:00—15:00 | 自测与修改 | **教师说：**“修改一条空值、一个文本数字或一条重复记录，先预测记录数和汇总如何变化，再运行。” | 学生完成一次最小修改并记录。 |
| 15:00—25:00 | 数据字典与流程图 | **教师说：**“数据字典写字段、含义、类型、允许值和缺失处理。流程图写读取、清洗、筛选、汇总和输出。” | 学生绘制并与代码对照。 |
| 25:00—35:00 | 同伴审阅 | **教师说：**“同伴只检查五件事：路径可复现、字段有口径、问题有日志、统计有分母、结论有边界。请留一条具体改进。” | 交换代码和说明，完成审阅表。 |
| 35:00—42:00 | 60秒数据说明 | **教师说：**“用 60 秒说清：问题是什么、清洗了什么、有效记录多少、发现什么、不能断言什么。” | 学生展示与回应一个追问。 |
| 42:00—45:00 | 提交与反思 | **教师说：**“写下 CSV 让你比 U3 多看见了什么，以及下一次你会先检查哪一项数据质量问题。” | 提交四类成果。 |

**试教后 P0 原则：** 只选择一个最明显的资源改进，例如增加路径自检、强化字符串到数字的类型追踪，或固定“有效数+问题数”输出；不要同时重写全部代码和评价量规。
