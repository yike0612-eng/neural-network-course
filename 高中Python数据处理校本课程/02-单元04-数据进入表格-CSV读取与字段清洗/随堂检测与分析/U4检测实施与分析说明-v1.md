# U4 随堂检测实施与分析说明 v1.0

本检测在 U4 第 5 课提交与同伴审阅后使用，建议用时 10 分钟。它用于判断学生是否能把 CSV 表格读成可解释的记录、按规则清洗并进行有口径的筛选与分组汇总，不用于公开排名、惩罚或高风险学生决策。

每份答卷只填写匿名 `response_id` 与 Q1—Q10 的选项。不得录入姓名、学号、成绩、联系方式、真实出入记录或其他敏感信息。运行分析脚本：

```bash
python analyze_u4_quiz.py u4_quiz_responses_template.csv u4_quiz_config.json --output-dir quiz_report
```

报告只输出题目、知识点和班级层面的正确率与诊断建议。教师应将结果与 CSV 脚本、数据字典、清洗前后行数对照、同伴审阅和质量说明结合解释。

| 标签 | 暂定阈值 | 建议行动 |
|---|---:|---|
| 稳定 | ≥ 80% | 在 U5 图表任务中复现字段口径和分母说明。 |
| 需巩固 | 60%—79% | 用 5—10 分钟补做字段类型、唯一键或分组表练习。 |
| 优先修订 | < 60% | 进入 U5 前只确定一个资源改进，例如增加 CSV 路径/类型侦察卡。 |

低正确率首先提示教师检查题目表述、样例结构、课堂练习次数、环境差异和时间安排，不能直接归因于学生能力。任何单题结果都不应单独决定是否推进 U5；应结合学生作品和课堂观察形成一个 P0 修订。

## 题目与课堂资源对照

| 题号 | 检查内容 | 主要课堂证据 |
|---|---|---|
| Q1—Q3 | CSV 首行、字典记录、字段类型 | 第 17 课字段名和类型侦察。 |
| Q4—Q7 | 缺失、重复、转换与记录去向 | 第 16—18 课质量表、清洗日志。 |
| Q8—Q9 | 筛选、分组与分母 | 第 19 课筛选表和分组汇总。 |
| Q10 | 证据与边界 | 第 20 课数据质量说明。 |

> U4 的检测结果只用于改进数据处理资源，不用于判断学生的长期能力、诚信、行为或个人表现。
