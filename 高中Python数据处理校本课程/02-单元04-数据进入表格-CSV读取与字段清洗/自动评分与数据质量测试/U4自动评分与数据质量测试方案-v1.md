# U4 自动评分与数据质量测试方案 v1.0

## 一、工具定位

本工具服务于 U4《数据进入表格：CSV读取与字段清洗》的最低可运行版本自检。它检查学生是否能按字段读取教学模拟 CSV、清洗 `visits` 与 `minutes`、保留问题日志、完成按 `space` 的有效记录汇总，并保护原始输入。工具输出分维度诊断，不替代教师对数据字典、流程图、6 组测试、两次规则实验和 150—250 字质量说明的人工评价。

它只适合在隔离目录中运行可信课堂代码，**不是安全沙箱**。评分器会拦截常见危险导入和调用，并为子进程设置超时，但不能保证对恶意 Python 代码的完整防护。

## 二、学生接口

学生文件命名为 `u4_submission.py`，至少实现：

```python
def read_rows(path):
    """读取 CSV，返回字典记录列表。"""
    ...


def clean_rows(rows):
    """返回 (valid_rows, issues, stats)。"""
    ...


def group_summary(valid_rows):
    """按 space 返回分组汇总。"""
    ...
```

为便于稳定测试，建议 `clean_rows` 的 `stats` 至少包含 `raw_count`、`valid_count`、`issue_count`、`review_count`；`group_summary` 的每组结果至少包含 `valid_count`、`total_visits`、`total_minutes`、`average_minutes`。学生可以使用列表、字典或元组表示结果，但必须在说明中写出结构。

## 三、评分维度

| 维度 | 权重 | 自动检查 |
|---|---:|---|
| CSV读取 | 20% | 字段名、6条记录、字典字段和原始值保持。 |
| 字段清洗 | 25% | 空值、空格数字、无效文本、负数的处理和原因。 |
| 质量日志与追溯 | 20% | 问题记录保留行号/标识、字段、原始值和原因；不覆盖原始数据。 |
| 分组汇总 | 20% | 仅用有效记录按 `space` 汇总，报告数、总量、平均值。 |
| 结构与复现 | 15% | 函数可导入，输入改动后结果随之变化，无明显危险调用。 |

评分器不强制唯一的重复规则，因为任务书要求学生先定义唯一键；它只检查重复或待复核信息是否存在并可解释。若学生未提供 `review_count`，应由教师根据质量说明人工补充。

## 四、测试场景

基础 CSV：

```csv
date,space,visits,minutes
2026-04-01,东区,42,35
2026-04-02,东区,,40
2026-04-03,西区,38,abc
2026-04-03,西区,38,45
2026-04-04,东区,51,50
2026-04-05,西区,44, 30 
```

评分器会额外生成以下变体：空值保留、空格数字保留、无效文本保留、负数替换、完整重复行和空间字段变更。每个变体都用于检查“输入改变—记录去向改变—汇总随之改变”是否成立。

## 五、运行方式

```bash
python grade_u4.py u4_submission.py --csv-path reading_space_raw.csv
```

如果未提供 CSV 路径，评分器使用内置教学模拟数据。输出可以保存为 JSON，供教师课后汇总：

```bash
python grade_u4.py u4_submission.py --json-result u4_result.json
```

## 六、反馈规则

若读取字段不完整，反馈“先打印字段名并核对文件路径”；若数值仍是字符串，反馈“对字段做显式类型转换并记录失败原因”；若有效行数与问题行数不能解释全部原始行，反馈“补齐记录去向”；若分组结果缺少分母，反馈“同时报告有效记录数”；若原始输入改变后输出不变，反馈“检查是否把输入写死”。

## 七、人工评价边界

教师仍需核对学生是否使用数据字典、是否解释唯一键、是否完成两次规则实验、是否保留原始文件、是否用“这组教学模拟数据”限定结论，以及是否把缺失或重复当作可随意修复的问题。自动分数只用于即时反馈和资源改进，不用于公开排名或高风险学生决策。
