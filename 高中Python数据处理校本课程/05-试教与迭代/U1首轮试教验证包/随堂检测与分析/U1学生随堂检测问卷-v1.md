### 1. 数据问题与边界

下列哪个问题可以由“某人一周的阅读分钟数”直接回答？

B. 这一周有几天阅读时间达到 30 分钟。  
C. 全校学生是否都喜欢阅读。  
D. 这个人未来一定会阅读更多。  

### 2. `print()` 的作用

```python

```

A. `print("今日达标")`  
B. `今日达标`  
C. 报错，因为文字不能输出。  
D. 30  

### 3. 变量与数据类型

```python

study_note = "今天读了科幻小说"
```

哪句话正确？

A. `reading_goal` 保存的是文字。  
B. `study_note` 保存的是数值。  
C. `reading_goal` 保存数值，`study_note` 保存文字。  
D. 两个变量都不能用 `print()` 输出。  

### 4. 条件边界

```python

goal = 30

    print("达标")
else:
    print("继续努力")
```

程序会输出什么？

A. `达标`，因为 30 等于 30，也满足“达到或超过”。  
B. `继续努力`，因为 30 不是大于 30。  
C. 两句话都会输出。  
D. 程序一定报错。

D. 它让 `print()` 永远不运行。
