# U1 随堂检测实施与分析说明 v1.0

## 一、实施边界

本检测用于 U1 第 5 课末的形成性诊断，也可用于试教后 10 分钟抽测。它不作为公开排名、惩罚或高风险成绩依据；不收集姓名、学号、联系方式、学习成绩或其他敏感个人信息。教师只保留班级汇总与题目层面的结果，用来选择 U1 的一项 P0 修订。

建议在学生完成程序自测后独立答题 10 分钟。收卷后由教师或助教将选项录入 `u1_quiz_responses_template.csv`；每行只代表一份匿名答卷，不需要填写能识别学生身份的信息。

## 二、答案与知识点映射

| 题号 | 正确选项 | 核心知识点 | 若错误较多，优先检查什么 |
|---:|---|---|---|
| 1 | B | 数据问题与结论边界 | 是否把“可计算事实”与“因果/普遍结论”混为一谈。 |
| 2 | B | `print()` 输出 | 是否把代码文本与输出文本混淆。 |
| 3 | C | 变量、数值与文字 | 是否遗漏引号，或不能区分变量名和值。 |
| 4 | A | `>=` 与边界值 | 是否误解“达到或超过”包含相等情况。 |
| 5 | A | 缩进与代码块 | 是否把缩进视为纯排版。 |
| 6 | D | 循环累计 | 是否能追踪 `total` 在每一轮的变化。 |
| 7 | A | 平均值 | 是否能把总量与天数对应起来。 |
| 8 | B | 调试循环 | 是否能从现象、位置、最小修改和验证开始。 |
| 9 | C | IPO：处理 | 是否能区分输入、处理与输出。 |
| 10 | A | 数据责任与结论边界 | 是否能对有限数据作有范围的解释。 |

## 三、分析脚本输出的含义

`analyze_u1_quiz.py` 会产生三类结果：一份 Markdown 班级报告、一份按题目的 CSV 汇总，以及一份按知识点的 CSV 汇总。脚本不生成学生排名，也不输出单份答卷分数；每一道题只统计作答人数、正确人数、正确率和需要优先处理的概念。

| 结果标签 | 条件 | 教师行动 |
|---|---|---|
| 稳定 | 正确率 ≥ 80% | 进入下一单元，但在例题中继续自然复现。 |
| 需巩固 | 正确率 60%—79% | 用 5—10 分钟的预测、手算或同伴解释补强。 |
| 优先修订 | 正确率 < 60% | 在进入 U2 前安排针对性巩固，并把对应资源列为 P0 候选。 |

这些区间是试教复盘的暂定工作阈值，不是学生分数等级。教师应同时阅读课堂观察、三类成果完成度和环境记录，避免只凭一套选择题决定资源修改。

## 四、使用步骤

1. 将匿名选项录入 `u1_quiz_responses_template.csv`，只保留 `response_id` 和 Q1—Q10。
2. 在命令行运行：

```bash
python analyze_u1_quiz.py u1_quiz_responses_template.csv --output-dir quiz_report
```

3. 打开 `quiz_report/U1随堂检测汇总报告.md`，先看“优先修订”题目，再对照本说明中的“若错误较多，优先检查什么”。
4. 结合 `U1试教汇总记录模板.csv` 与三类成果情况，仅确定一项 P0 修订。

> 即使自动分析显示某题正确率低，也应先检查题干是否清楚、录入是否正确、课堂是否有足够练习机会，再归因于学生能力。
