# U6 随堂检测实施与分析说明 v1.0

本检测安排在第 30 课项目展示与复盘之后，建议用时 10 分钟。检测用于形成性改进，检查学生能否把问题、数据、处理、表达和责任连成项目链；不用于公开排名或高风险学生决策。

答卷仅记录匿名 `response_id` 与 Q1—Q10 选项，不录入姓名、学号、成绩或其他敏感信息。可复用课程技能中的匿名分析脚本：

```bash
python analyze_anonymous_quiz.py u6_quiz_responses_template.csv u6_quiz_config.json --output-dir quiz_report
```

| 标签 | 正确率 | 建议行动 |
|---|---:|---|
| 稳定 | ≥ 80% | 保留项目流程，进入课程复盘或下轮迭代。 |
| 需巩固 | 60%—79% | 在项目展示前补做对应的卡片或流程图。 |
| 优先修订 | < 60% | 只选择一个 P0 资源改进，例如增加问题卡、数据字典样例或伦理声明模板。 |

## 诊断分组

| 题目 | 主要能力 | 应结合审阅的项目证据 |
|---|---|---|
| Q1—Q3 | 问题界定、数据字典和可回答性 | 问题卡、字段口径和限制表。 |
| Q4—Q5 | 处理流水线与最小测试 | 流程图、测试记录和代码运行证据。 |
| Q6—Q7 | 建议边界与低风险数据 | 一页产品、数据来源和伦理声明。 |
| Q8—Q10 | 同伴复核、聚焦迭代与复盘 | 同伴审阅表、P0 修订记录和项目复盘。 |

教师解释低正确率时，应先审阅项目任务说明、样本范围、课堂时间、协作分工和工具可用性，不应直接归因于学生能力。U6 的最终判断必须结合小组数据产品、项目知识图、复盘和伦理声明；检测只提供一个班级层面的改进入口。

> U6 的目标不是让学生对校园作出宏大判断，而是让他们经历一次问题可界定、数据可追溯、处理可复现、建议可讨论、边界可说明的完整数据项目。
