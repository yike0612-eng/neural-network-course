# U6《我的校园数据微项目》学生学习单 v1.0

**课程：**《用 Python 读懂日常数据》  
**对象：** 高一、高二；已完成 U1—U5  
**课时：** 5 × 45 分钟（第 26—30 课）  
**项目主题：**《我的校园数据微项目：从一个小问题到一条负责任的数据建议》  
**数据边界：** 只使用教师批准的教学模拟数据、公开脱敏数据或教师提供的汇总数据。不得采集姓名、成绩、健康、家庭、联系方式、精确位置等真实个人信息；不得进行个人排序、预测或资源分配。

## 一、这不是“大研究”，而是一个可复核微项目

U6 是整门课程的收束。你将把 U1—U5 学到的程序、规则、清洗、表格、图表和边界表达串成一条完整责任链。但你不需要在五节课里完成一个无限开放的研究项目。

本项目只允许：

> **一个小问题、一份批准数据、一项核心指标、一张主图、一条谨慎建议、一次 P0 修订。**

这六项限额不是降低标准，而是让你把时间留给最重要的事情：问题是否可回答、数字是否可追溯、图表是否清楚、建议是否没有超出证据。

### 三类证据标准

| 证据层 | 你要交什么 | 最低完成标准 |
|---|---|---|
| **产品层** | 一份可运行的项目脚本、一个主汇总或主图、一页数据产品。 | 使用批准数据包可重新运行；更改一条允许修改的模拟输入后，输出变化可解释。 |
| **解释层** | 问题卡、数据字典、六步流水线、统计口径与数据范围说明。 | 读者能知道问题、字段、处理步骤、分母和主图从哪里来。 |
| **责任层** | 同伴审阅、一次 P0 修订、个人责任卡、伦理与边界声明。 | 能说明一项项目限制、一项改进依据和一条不能据此推出的结论。 |

## 学习单完成判据
