# 高中 Python 数据处理校本课程实施大礼包 v1.0

## 一、课程用途

本大礼包面向高一、高二日常 Python 通识入门课程，覆盖 **30 学时、6 个单元、每单元 5 课时**。课程用“**问题 → 数据 → 程序 → 结果 → 解释与边界**”贯穿全部学习活动，并以**产品层、解释层、责任层**三类证据组织评价。资源以普通 Windows 机房、Python 3.10+、可离线实施为基本条件设计。

> **实施原则：** 先保证一个小问题、一份合规数据和一条可运行处理链，再追求图表丰富或项目扩展。所有自动评分和自动验收均只在受控课堂环境中运行可信学生文件，不构成安全沙箱。

## 二、首次使用的建议顺序

教师第一次实施时，建议先阅读 `01-课程蓝图/30学时课程总体蓝图-v1.md`、`03-共用资源/课程资源使用说明.md` 和本说明，再按 U1→U6 顺序进入单元目录。每个单元均应依次使用：教师指导书或实施指导书、五课时逐字稿、学生学习单、形成性检测、自动自检资源与结项项目任务书。

| 时间 | 单元 | 核心产出 | 首次实施的最低目标 |
|---:|---|---|---|
| 1—5 | U1 数据侦探的第一步 | 七日专注节奏小报 | 能用变量、输入输出和条件判断回答一个小问题。 |
| 6—10 | U2 让程序替我做选择 | 校园课间活动建议助手 | 能把规则转成条件分支，并说明规则边界。 |
| 11—15 | U3 数据变形记：列表与批量清洗 | 阅读记录质量报告 | 能批量处理记录并留下问题日志。 |
| 16—20 | U4 数据进入表格：CSV读取与字段清洗 | 校园阅读空间表格报告 | 能读入 CSV、清洗字段、报告有效数与问题数。 |
| 21—25 | U5 让图表说清楚 | 一页数据故事 | 能选择适当图表、说明分母和识别误导风险。 |
| 26—30 | U6 我的校园数据微项目 | 校园数据微项目 | 能完成一个小而完整的数据项目与一次 P0 修订。 |

## 四、最小运行环境

| 项目 | 最低要求 | 教师课前验证方式 |
|---|---|---|
| 操作系统 | Windows 10/11 普通机房 | 确认学生账户可在课程文件夹读写。 |
| Python | Python 3.10 或更高版本 | 在命令提示符运行 `python --version`。 |
| 网络 | 无需联网 | 使用已随包提供的教学模拟数据与本地脚本。 |
| 基础库 | Python 标准库 | U4 使用 `csv`；不把 `pandas` 作为最低要求。 |
| 绘图环境 | 两条路径 | 代码绘图可用则使用；不可用时按预制图路径完成同一图表合同。 |
| 运行位置 | 本地受控目录 | 自动评分器只运行当前课堂可信文件，且不在公共共享目录执行。 |

建议将压缩包完整解压到英文路径较短的目录，例如 `D:\PythonK12DataCourse\`。U4 以后涉及 CSV 时，脚本和数据文件应放在同一项目目录；若学校策略限制双击 `.py` 文件，则由教师提供统一的命令提示符运行演示。

## 五、数据与隐私边界

本课程优先使用教学模拟数据、公开数据或经教师审核的脱敏数据。学生作品、随堂检测和项目材料中不得收集或呈现姓名、学号、成绩、健康信息、精确位置、联系方式、可识别人脸或其他敏感个人信息。形成性检测采用随机编号，只做班级整体错因分析；不生成个人排名。

若学生希望研究“校园现象”，教师应先审查问题和数据范围。可以研究教师提供的模拟阅读记录、虚构场景数据或已脱敏的公开汇总；不应自行开展涉及同学个人行为、成绩、出入地点或隐私偏好的调查。发现风险时，应立即缩小问题、替换为模拟数据或停止该数据收集方案。

## 六、评价与反馈方式

| 证据层 | 教师收集的材料 | 最低判断问题 |
|---|---|---|
| 产品层 | 可运行代码、处理结果、主图或一页产品 | “作品能否打开、运行，并产生对应结果？” |
| 解释层 | 数据字典、清洗日志、统计量说明、图表合同 | “每个数字的来源、范围、规则和分母能否说清？” |
| 责任层 | 边界句、误导检查、同伴反馈、P0修订记录 | “是否避免过度推断，并根据证据完成一次修订？” |

自动评分器只用于技术底线诊断。最终结项评价应以小组为单位综合三类证据，并使用描述性反馈指出下一步可以改进的一个关键点。不要把随堂检测结果或自动分数直接转换为对学生的高风险结论。

## 七、试教与迭代建议

首次试教建议从 U1 完整跑通，再把 U1 的“环境是否可用、学生在哪一步停滞、哪条提示最有效”记录到 `05-试教与迭代/`。每轮只处理一个 P0 问题：例如统一 Python 路径、强化字符串与数字的区别、补全分母、准备预制图路径或收紧 U6 项目范围。不要因一次试教中出现多个问题而同时重写课程全部资源。

## 八、压缩包范围

`高中Python数据处理校本课程-大礼包-v1.zip` 包含本课程目录的可实施资源：课程蓝图、U1—U6 指导书与学生学习单、逐字稿、检测与分析脚本、自动评分/验收、结项任务书、试教与汇报材料及本说明。压缩包排除 Python 缓存、临时测试结果和压缩包自身，避免将无关文件带入教师电脑。
