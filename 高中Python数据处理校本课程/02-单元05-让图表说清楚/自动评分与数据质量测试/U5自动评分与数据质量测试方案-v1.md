# U5 自动评分与数据质量测试方案 v1.0

## 一、工具定位

本工具用于《一页数据故事》结项项目的最低可运行版本自检。它不评价配色审美，也不替代教师阅读学生的一页故事、图表选择图、误导检查单和 150—250 字边界说明。它主要检查：统计量计算是否基本正确，图表类型是否与问题匹配，图表口径是否完整，样本和分母是否被说明，结论是否保留边界。

本工具运行可信的课堂提交代码，**不是安全沙箱**。静态检查会拦截常见危险导入和调用；教师仍应在隔离目录中运行，并人工审阅最终表达。

## 二、稳定提交接口

学生提交 `u5_submission.py`，建议至少实现：

```python
def summarize(values):
    """返回 mean、median、count、total。"""
    ...


def choose_chart(question_type, data_shape):
    """返回 bar、line 或 pie。"""
    ...


def build_story(question, values, question_type, data_shape):
    """返回一页故事的结构化说明。"""
    ...
```

`build_story` 至少应返回以下字段：

```python
{
    "question": "问题文字",
    "statistic": "mean",
    "chart_type": "bar",
    "count": 7,
    "denominator": "7条有效模拟记录",
    "observation": "数据支持的观察",
    "boundary": "不能据此断言的结论"
}
```

学生可以使用其他内部函数，但必须能说明结构。

## 三、评分维度

| 维度 | 权重 | 自动检查 |
|---|---:|---|
| 统计量计算 | 25% | count、total、mean、median 基本正确，空列表有明确处理。 |
| 图表选择 | 20% | 时间序列优先 line，类别比较优先 bar，组成比例才可考虑 pie。 |
| 图表口径 | 20% | 故事结构包含问题、统计量、数量/分母和图表类型。 |
| 边界表达 | 20% | observation 与 boundary 非空，且没有把模拟数据直接说成普遍规律或因果。 |
| 输入响应与结构 | 15% | 输入变化能改变统计结果；函数可导入；无明显危险调用。 |

评分器不判断视觉美观，不强制学生只能使用一种图表；如果学生有合理理由选择不同图表，教师可在自动反馈之外人工调整。

## 四、内置测试场景

默认测试数据为教学模拟数据：

```python
[25, 35, 40, 30, 50, 45, 35]
```

测试包括：正常列表、含异常高值列表、单值列表、空列表、时间序列选择、类别比较选择、组成比例选择、输入变化响应和边界禁用词检查。自动测试只检查结构和明显错误，不把测试结果视为学生最终成绩。

## 五、运行方式

```bash
python grade_u5.py u5_submission.py
python grade_u5.py u5_submission.py --json-result u5_result.json
```

若学生选择直接绘图而未使用结构化故事函数，可通过模板把手工图表中的问题、统计量、分母、观察和边界录入后再进行人工评分。

## 六、反馈规则

若统计量缺失，反馈“先写清问题需要比较什么，再决定平均数、中位数或比例”；若图表类型与数据形状不匹配，反馈“先判断横轴是时间、类别还是组成”；若没有分母，反馈“在结论中补充有效记录数或比例分母”；若 observation 为空，反馈“写一条数据实际支持的观察”；若 boundary 为空或含因果断言，反馈“增加样本范围和不能据此断言的内容”。

## 七、人工评价边界

教师仍需核对图表标题、轴标签、单位、图例、坐标轴、样本范围、误导检查单和同伴反馈。自动评分不判断图表是否在视觉上夸大差异，也不替代教师判断学生是否真正理解图表与证据之间的关系。
