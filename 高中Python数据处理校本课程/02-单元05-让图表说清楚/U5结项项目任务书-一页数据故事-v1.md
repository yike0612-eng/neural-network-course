# U5 单元结项项目任务书

## 《一页数据故事：图表能把发现说清楚吗？》

**项目类型：** 个人完成或两人结对完成、同伴展示的 U5 结项项目。  
**建议用时：** 第 24—25 课内完成，另可用 20—30 分钟完善。  
**你将交付：** 一页数据故事、一个可复现的 Python 绘图脚本或绘图记录、一张图表选择图、一份图表误导检查单和一段 150—250 字的数据边界说明。  
**数据来源：** 教师提供的校园阅读空间或一周活动教学模拟数据；不得使用真实学生姓名、成绩、健康、家庭或精确位置数据。

> 你的目标不是做一张“好看”的图，而是让读者沿着“问题—证据—解释—边界”读懂一项有限、可复核的发现。

## 一、情境与任务

学校数据小组准备制作一页面向同学的教学数据故事。教师提供一组已经过基本清洗的模拟数据，例如不同阅读空间的有效记录汇总或一周模拟阅读分钟数。你需要选择一个小问题，使用合适的统计量和图表回答它，并主动检查图表是否可能误导读者。

你可以从以下问题中选择一个，也可以提出同结构的新问题：

1. 在这组模拟记录中，东区与西区的平均阅读分钟数有何差异？  
2. 一周模拟阅读分钟数的变化适合用什么图表表达？  
3. 不同空间的有效记录数量或总分钟数如何比较？  
4. 哪一种统计量更适合描述这组记录中的“典型值”？

你的结论必须限定为“这组教学模拟数据中观察到的现象”，不能把图表结果直接说成真实校园规律、个人能力差异或因果结论。

## 二、给定数据与字段口径

可使用 U4 结项项目的清洗后结果，也可使用教师提供的同结构数据。下列数据只作课堂示例：

```python
space_summary = {
    "东区": {"valid_count": 2, "total_minutes": 90, "average_minutes": 45},
    "西区": {"valid_count": 2, "total_minutes": 75, "average_minutes": 37.5},
}

weekly_minutes = [25, 35, 40, 30, 50, 45, 35]
weekly_labels = ["周一", "周二", "周三", "周四", "周五", "周六", "周日"]
```

| 字段或指标 | 含义 | 报告时必须说明 |
|---|---|---|
| `valid_count` | 进入本次统计的有效记录数。 | 不能省略分母。 |
| `total_minutes` | 有效记录的分钟数总和。 | 不能与平均值混用。 |
| `average_minutes` | 总分钟数除以有效记录数。 | 说明有效记录范围。 |
| `weekly_minutes` | 一周教学模拟分钟序列。 | 不能据此断言真实习惯或长期趋势。 |

## 三、最低可运行版本

你的作品至少要完成以下步骤：

1. 写出一个可回答的问题，并指出所需字段或指标。  
2. 选择平均数、中位数或比例中的至少一种，并写出选择理由。  
3. 选择柱状图、折线图或饼图中的一种，并说明为什么不用另一种。  
4. 使用 Python 或课堂提供的绘图工具生成一张带标题、横轴、纵轴、单位和必要图例的图表。  
5. 在图表旁写出一条数据支持的观察、一条谨慎解释和一条不能断言的结论。  
6. 使用误导检查单检查坐标轴、分母、样本范围、标签、图例和因果表达。

## 六、图表制作要求

图表必须具备以下基本信息：

| 检查项 | 我的作品是否具备 |
|---|---|
| 标题说明比较对象和指标 | □ |
| 横轴有类别或时间标签 | □ |
| 纵轴有指标名称和单位 | □ |
| 图例或颜色含义清楚 | □ |
| 有效记录数或分母可追溯 | □ |
| 没有用装饰替代数据标签 | □ |

如果使用 `matplotlib`，最低代码路径可以从以下结构开始：

```python
import matplotlib.pyplot as plt

labels = ["东区", "西区"]
values = [45, 37.5]

plt.bar(labels, values)
plt.title("教学模拟数据中的平均阅读分钟数")
plt.xlabel("模拟空间")
plt.ylabel("平均分钟数")
plt.tight_layout()
plt.show()
```

代码中的数据、标题和单位必须与你的实际问题一致。不能只复制示例而不解释字段口径。

## 八、一页数据故事结构

一页作品必须按下列顺序组织：

### 1. 问题

用一句话写清楚你想比较或观察什么。

### 2. 证据

放置图表和必要统计量，写明有效记录数、数据范围或分母。

### 3. 解释

写出一条数据支持的观察，不添加数据没有提供的原因。

### 4. 边界

写出这组数据不能支持的一个结论，并说明下一步还需要什么数据。

推荐句式：

> 在这组教学模拟数据中，______ 的 ______ 高于/低于 ______；该比较基于 ______ 条有效记录。这个结果只能说明 ______，不能据此断言 ______，因为 ______。
