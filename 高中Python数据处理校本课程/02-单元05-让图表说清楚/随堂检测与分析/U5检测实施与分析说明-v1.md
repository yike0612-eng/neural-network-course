# U5 随堂检测实施与分析说明 v1.0

本检测安排在 U5 第 25 课数据故事展示后，建议用时 10 分钟。检测用于形成性改进，检查学生是否能选择统计量、匹配图表、补齐图表口径并说明证据边界；不用于公开排名或高风险学生决策。

答卷仅记录匿名 `response_id` 与 Q1—Q10 选项。不得录入姓名、学号、成绩、健康或其他敏感信息。运行通用分析脚本：

```bash
python analyze_u5_quiz.py u5_quiz_responses_template.csv u5_quiz_config.json --output-dir quiz_report
```

| 标签 | 正确率 | 建议行动 |
|---|---:|---|
| 稳定 | ≥ 80% | 进入 U6 时要求每组继续提交图表四要素与边界说明。 |
| 需巩固 | 60%—79% | 用一个小数据集补做统计量和图表配对练习。 |
| 优先修订 | < 60% | 只确定一个 P0 资源改进，例如增加“分母卡”或“误导图对照卡”。 |

## 诊断分组

| 题目 | 主要能力 | 课堂证据 |
|---|---|---|
| Q1—Q3 | 平均数、中位数、比例与分母 | 第 21 课统计量选择说明。 |
| Q4—Q6 | 图表类型与四要素 | 第 22—23 课图表合同和代码图。 |
| Q7—Q9 | 坐标轴、样本范围、相关与因果 | 第 24 课误导图修正说明。 |
| Q10 | 数据故事表达链 | 第 25 课 60 秒数据故事。 |

教师解释低正确率时，应先检查图表样例、题目表述、数据口径、绘图环境、课堂时间和学生作品，不应直接把结果归因于学生能力。检测结果应与数据故事页、图表选择图和误导检查单共同审阅，并在推进 U6 前只做一个聚焦修订。

> 一个图表即使数值计算正确，也可能因缺少单位、分母、样本范围或因果边界而产生误读；因此 U5 的自动分析只提供诊断入口，最终判断仍需要教师阅读学生的解释。
