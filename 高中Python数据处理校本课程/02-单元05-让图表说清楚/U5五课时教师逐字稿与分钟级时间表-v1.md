# U5《让图表说清楚》五课时教师逐字稿与分钟级时间表 v1.0

**对象：** 高一、高二，已完成 U1—U4。  
**课时：** 5 × 45 分钟。  
**主题：** 统计量与基础图表的选择、绘制和误导检查。  
**基础路径：** Python 与 `matplotlib`；如环境未安装扩展库，教师可用预制图表完成核心判断，代码绘图作为可选路径。  
**数据边界：** 全部使用教学模拟或公开、脱敏数据，不采集真实学生的成绩、健康、家庭或精确位置等敏感信息。

## 一、教学模拟数据

本单元默认使用 U4 清洗后的模拟校园阅读空间汇总，也可以使用教师提供的同结构模拟数据。课堂不把图表结论表述为真实群体规律。

```python
space_summary = {
    "东区": {"valid_count": 2, "total_minutes": 90, "average_minutes": 45},
    "西区": {"valid_count": 2, "total_minutes": 75, "average_minutes": 37.5},
}

weekly_minutes = [25, 35, 40, 30, 50, 45, 35]
weekly_labels = ["周一", "周二", "周三", "周四", "周五", "周六", "周日"]
```

数字是教学模拟数据，重点是选择统计量、图表和表达方式，不是得出真实校园判断。

# 第 21 课：统计量帮助我们看什么？

**本课目标：** 区分平均数、中位数和比例的用途；理解统计量依赖数据口径与分母；能为一个问题选择合适统计量。

| 时间 | 教学环节 | 教师逐字稿与操作 | 学生活动与观察 |
|---|---|---|---|
| 0:00—5:00 | 从U4进入U5 | **教师说：**“U4 我们得到了一张可信汇总表，但表里的数字还不会自动讲故事。今天要问的是：一个数字到底帮助我们看什么？平均值不是万能答案。” | 学生回顾有效记录数、总量和平均值。 |
| 5:00—12:00 | 三种统计量 | **教师说：**“平均数把总量平均分配；中位数把数据排序后看中间位置；比例回答‘其中有多少’。先不要算，先看问题需要哪一种。” | 学生为三个问题配统计量。 |
| 12:00—22:00 | 手算与比较 | 给出 `[10, 10, 10, 10, 100]`。**教师说：**“平均数是多少？中位数是多少？如果要描述‘典型的一次记录’，哪个更稳妥？答案取决于问题。” | 学生手算并解释异常值影响。 |
| 22:00—32:00 | 分母意识 | **教师说：**“比例必须说明分母。‘东区占 40%’要追问：占什么的 40%？记录数、访问次数，还是总分钟数？” | 学生补全比例句子的分母。 |
| 32:00—40:00 | 数据口径检查 | **教师说：**“两个平均值只有在字段、单位、有效记录口径一致时才适合比较。” | 学生检查东区/西区汇总表。 |
| 40:00—45:00 | 退出卡 | **教师说：**“写出一个适合用中位数的问题，并写明它的分母或数据范围。” | 提交退出卡。 |

**即时调整：** 若学生把中位数理解成“最大和最小的平均”，用五个数排序演示；若学生忽略分母，禁止使用孤立百分比。

# 第 22 课：图表不是装饰

**本课目标：** 判断柱状图、折线图和饼图的适用情境；说明类别、时间序列和组成比例的差异；识别图表与数据类型不匹配。

| 时间 | 教学环节 | 教师逐字稿与操作 | 学生活动与观察 |
|---|---|---|---|
| 0:00—5:00 | 看图猜问题 | 展示三张不标标题的图。**教师说：**“先不要猜结论，只问：这张图最可能想比较什么？横轴和纵轴各是什么？” | 学生为图表补问题。 |
| 5:00—13:00 | 柱状图 | **教师说：**“柱状图适合比较离散类别，例如东区和西区的平均分钟数。每根柱子的类别、数值、单位都要能读出来。” | 学生完成类别—指标配对。 |
| 13:00—21:00 | 折线图 | **教师说：**“折线图暗示顺序和变化，适合有时间顺序的数据。把没有时间顺序的类别连起来，读者可能会误以为它们有连续变化。” | 学生判断一组折线图是否合适。 |
| 21:00—29:00 | 饼图与组成 | **教师说：**“饼图只适合组成部分能够构成一个整体，类别不宜太多。若数据不是同一个总量的组成，就不要用饼图。” | 学生检查饼图配对卡。 |
| 29:00—38:00 | 图表选择挑战 | **教师说：**“为‘每日分钟变化’、‘不同空间平均值’、‘阅读类型构成’各选一种图，并说出不用另一种图的理由。” | 小组完成选择与理由。 |
| 38:00—45:00 | 退出卡 | **教师说：**“写一句图表选择原则：我的横轴是什么，图表让读者比较什么？” | 提交退出卡。 |

**即时调整：** 若学生只按图表外观选择，要求先写问题、变量类型和比较目的再选图。

# 第 23 课：Python 绘制第一张图

**本课目标：** 使用 `matplotlib` 绘制基础柱状图或折线图；正确设置标题、坐标轴、单位和标签；能从代码回溯图表数据。

| 时间 | 教学环节 | 教师逐字稿与操作 | 学生活动与观察 |
|---|---|---|---|
| 0:00—5:00 | 绘图前检查 | **教师说：**“今天不是先敲代码，而是先写图表合同：我要回答什么问题，横轴、纵轴、单位、数据范围是什么？” | 学生填写图表合同。 |
| 5:00—14:00 | 代码骨架 | 演示 `plt.bar(labels, values)`、`plt.title()`、`plt.xlabel()`、`plt.ylabel()` 和 `plt.show()`。**教师说：**“每一行代码都对应图上的一个可读元素。” | 学生运行最小程序。 |
| 14:00—24:00 | 标题与单位 | **教师说：**“标题不能只写‘数据图’，要写清比较对象和指标。纵轴不能只有数字，要有单位。” | 学生修改模糊标题和坐标轴。 |
| 24:00—33:00 | 图表—数据回溯 | **教师说：**“请从柱子反向找到原始列表中的一个值，再把一个值改掉，预测图表怎样变化。” | 学生修改一个输入并验证。 |
| 33:00—40:00 | 同伴检查 | **教师说：**“同伴不评价好不好看，只检查四件事：标题、横轴、纵轴、单位。” | 交换图表完成检查单。 |
| 40:00—45:00 | 退出卡 | **教师说：**“写出一项图表元素缺失会造成的误读。” | 提交退出卡。 |

**即时调整：** 若环境不能运行 `matplotlib`，使用教师预制图表完成判断，并让学生提交代码草稿和四要素检查单。

# 第 24 课：图表怎样误导读者？

**本课目标：** 识别截断坐标轴、比例失真、样本不足、图例缺失和混淆相关与因果等问题；修正一张误导图并说明改动理由。

| 时间 | 教学环节 | 教师逐字稿与操作 | 学生活动与观察 |
|---|---|---|---|
| 0:00—7:00 | 误导图对照 | 展示同一组数据的两个版本。**教师说：**“两张图都可能没有算错，但读者感受到的差异很大。我们今天检查图表如何制造不必要的印象。” | 学生圈出视觉差异。 |
| 7:00—15:00 | 坐标轴检查 | **教师说：**“柱状图的零点、刻度和单位会影响比较。截断纵轴可能放大差异，除非你明确说明并选择合适图形。” | 学生修正纵轴和标题。 |
| 15:00—23:00 | 比例与样本 | **教师说：**“一个很高的百分比，如果只有两条记录，不能自动代表稳定规律。图表要同时告诉读者样本范围和分母。” | 学生为图表补样本数和分母。 |
| 23:00—31:00 | 相关与因果 | **教师说：**“图表显示两个变量一起变化，不等于一个变量造成另一个变量。我们只写数据支持的观察。” | 学生将因果句改为谨慎描述。 |
| 31:00—39:00 | 误导图修正 | **教师说：**“请改一张图，并在旁边写‘我改了什么、为什么、读者会少误解什么’。” | 完成修正和说明。 |
| 39:00—45:00 | 退出卡 | **教师说：**“写出你现在最先检查的一个图表风险。” | 提交退出卡。 |

**即时调整：** 若学生把所有非零起点都判为错误，说明折线图、比例图和呈现目的存在差异，回到“图表合同”。

# 第 25 课：怎样讲清一个数据发现？

**本课目标：** 用“问题—证据—解释—边界”完成一页数据故事；用 60 秒说明图表；回应一个关于口径、样本或因果的追问。

| 时间 | 教学环节 | 教师逐字稿与操作 | 学生活动与观察 |
|---|---|---|---|
| 0:00—5:00 | 作品任务 | **教师说：**“今天不是做海报装饰，而是把一个明确问题讲清楚。你的页面必须让别人知道问题、证据、解释和不能断言什么。” | 学生选择 U4 模拟数据或教师提供数据。 |
| 5:00—13:00 | 四句模板 | **教师说：**“第一句是问题，第二句是证据，第三句是基于证据的谨慎解释，第四句是边界。缺一项，数据故事就可能变成口号。” | 学生填写四句模板。 |
| 13:00—25:00 | 图表制作 | **教师说：**“先选能回答问题的图，再补标题、单位、图例和数据范围。颜色只能帮助区分，不能代替标签。” | 学生完成图表和说明。 |
| 25:00—34:00 | 60秒试讲 | **教师说：**“请在 60 秒内讲完，并让同伴只追问一个问题：分母是什么、数据从哪里来、能不能说因果。” | 学生展示与同伴追问。 |
| 34:00—40:00 | 误导检查 | **教师说：**“根据检查单再看一次自己的作品。发现问题不是失败，而是图表发布前的必要步骤。” | 学生完成图表误导检查单。 |
| 40:00—45:00 | 提交与复盘 | **教师说：**“提交数据故事页、图表选择图和误导检查单，并写下下一次会先检查什么。” | 提交三项成果。 |

**试教后 P0 原则：** 只选择一个最明显的改进，例如增加图表合同、强化分母说明或提供无扩展库备选路径；不同时重写整套课程。
