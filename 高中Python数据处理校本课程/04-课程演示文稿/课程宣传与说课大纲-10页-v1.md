# 高中Python数据处理校本课程宣传与说课大纲 (10页)

## 第1页：封面
**标题**：从日常问题到负责任的建议
**副标题**：高中 Python 数据处理校本课程说课与宣传
**核心内容**：课程主题、适用对象（高一、高二）、30学时。
**讲者意图**：开门见山，点明课程不只是学语法，而是学“处理问题”。

## 第2页：为什么我们需要这门课？
**标题**：不仅是编程，更是现代数据素养
**核心内容**：
- 痛点：学生能背语法，但遇到真实表格不知所措；能画出图表，但容易过度推断。
- 目标：用 Python 把日常问题处理成清楚、可信且有边界的数据结论。
- 路径：问题 → 数据 → 程序 → 结果 → 解释与边界。
**讲者意图**：确立课程的通识定位与核心价值。

## 第3页：30学时，六个阶梯
**标题**：课程总体蓝图：从认知到创造
**核心内容**：
- U1—U3：建立编程与问题意识（运行程序、条件循环、列表字典）。
- U4—U6：走向可信数据产品（CSV清洗、证据表达、综合创作）。
- 认知进阶：记忆/理解 → 应用/分析 → 评价/创造。
**讲者意图**：展示课程的结构感和布鲁姆认知进阶。

## 第4页：U4 解决“数据可信”
**标题**：U4：数据能不能进入分析？
**核心内容**：
- 从内存记录走向真实文件（CSV）。
- 核心规范：原始记录不可覆盖、清洗规则先于代码、保留问题日志。
- 产出：清洗前后记录数说明，知道结果由哪些有效记录构成。
**讲者意图**：解释后半程的起点：把错误转化为规则判断。

## 第5页：U5 解决“表达可信”
**标题**：U5：分析结果能否被正确理解？
**核心内容**：
- 桥梁作用：从数字汇总走向证据表达。
- 核心抓手：图表合同、分母说明、误导检查。
- 亮点：代码绘图与预制图双路径，评价同一标准，避免用一张图过度推断。
**讲者意图**：说明U5的重点不在于炫技，而在于负责任的解释。

## 第6页：U6 解决“行动可信”
**标题**：U6：小而完整的责任性创造
**核心内容**：
- 目标：把证据链组织成有边界的公共表达。
- 六项限额：小问题、批准数据、一项指标、一张主图、谨慎建议、一次P0修订。
- 五课时节奏：范围冻结 → 绿线跑通 → 质量与变化 → 主图与故事 → 汇报修订。
**讲者意图**：展示U6如何把项目式学习落地为学生可驾驭的最小产品。

## 第7页：三类证据评价体系
**标题**：产品层、解释层、责任层
**核心内容**：
- 产品层：程序可运行，图表有要素（自动评分/验收）。
- 解释层：说明口径、分母、清洗规则和图表选择。
- 责任层：同伴复核、伦理声明、不使用敏感个人信息。
**讲者意图**：展示评价的立体性，自动工具不替代人工判断。

## 第8页：U6的综合评分标准
**标题**：六维量规与综合评价
**核心内容**：
- 权重分配：技术实现(30%)、数据与证据(30%)、解释与表达(25%)、责任与协作(15%)。
- 评价重点：不以视觉效果替代数据处理，强调同伴质询与修订。
- 反馈方式：组级描述性反馈，不以自动分数作个人排名。
**讲者意图**：具体展示期末结项的严谨性和科学性。

## 第9页：可直接落地的课程大礼包
**标题**：完整配套，即刻开课
**核心内容**：
- 资源覆盖：指导书、逐字稿、学习单、自动评分/验收、随堂检测、结项任务书。
- 环境友好：普通Windows机房、离线运行、Python标准库起步。
- 教师支持：分钟级时间表、即时调整建议、试教复盘策略。
**讲者意图**：打消开课顾虑，展示课程的成熟度和可实施性。

## 第10页：结语
**标题**：让数据成为看见世界的可靠透镜
**核心内容**：
- 愿景回顾：让每位学生都能用 Python 负责任地回答日常问题。
- 欢迎交流与试教。
**讲者意图**：总结升华，呼吁行动。
